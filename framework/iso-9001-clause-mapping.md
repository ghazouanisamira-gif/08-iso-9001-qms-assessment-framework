# ISO 9001 Clause Mapping

## Purpose

Map ISO 9001:2015 requirements to evidence, current state, gaps, risks, actions and follow-up.

## Clause Structure

| Clause | Main Themes |
|---|---|
| **4 — Context** | Context, interested parties, scope, processes |
| **5 — Leadership** | Leadership, policy, roles and responsibilities |
| **6 — Planning** | Risks, opportunities, objectives, changes |
| **7 — Support** | Resources, competence, awareness, communication, documented information |
| **8 — Operation** | Operational planning, customer requirements, service provision, external providers |
| **9 — Performance Evaluation** | Monitoring, customer satisfaction, analysis, audit, management review |
| **10 — Improvement** | Nonconformity, corrective action, continual improvement |

## Traceability Logic

**Requirement → Evidence → Current State → Gap → Risk / Priority → Action → Follow-up**

## Use

The mapping supports:

- traceability;
- evidence-based diagnosis;
- gap identification;
- risk prioritization;
- action planning;
- implementation monitoring.

> This is an academic analysis framework and not a certification checklist or audit conclusion.
