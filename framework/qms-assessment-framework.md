# QMS Assessment Framework

## Purpose

A reusable framework for assessing the maturity of Quality Management System practices and translating findings into improvement priorities.

## Assessment Dimensions

1. Organizational context
2. Interested parties
3. Process architecture
4. Leadership and responsibilities
5. Risk-based thinking
6. Quality objectives and KPIs
7. Competence and awareness
8. Documented information
9. Operational control
10. Performance evaluation
11. Corrective action
12. Continual improvement

## Assessment Flow

**Collect evidence → Assess current state → Identify gaps → Evaluate risk → Prioritize → Define actions → Monitor**

## PMO Perspective

The framework can be used as a project baseline to structure workstreams, owners, milestones, dependencies and reporting.
