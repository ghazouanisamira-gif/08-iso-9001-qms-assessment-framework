# QMS Assessment Framework

## Purpose

A reusable framework for assessing the maturity of Quality Management System practices and translating findings into structured improvement priorities.

## Assessment Dimensions

1. Organizational context
2. Interested parties
3. QMS scope
4. Process architecture and interactions
5. Leadership and responsibilities
6. Risk-based thinking
7. Quality objectives and KPIs
8. Competence and awareness
9. Documented information
10. Operational control
11. Performance evaluation
12. Corrective action
13. Continual improvement

## Assessment Flow

**Collect Evidence → Assess Current State → Identify Gaps → Evaluate Risk → Prioritize → Define Actions → Monitor**

## Evidence Categories

Evidence may include:

- process documentation;
- organizational responsibilities;
- procedures and work instructions;
- performance indicators;
- training and competence records;
- customer feedback;
- audit or review outputs;
- corrective actions;
- improvement initiatives.

## PMO Perspective

The framework can be used as a project baseline to define:

- workstreams;
- owners;
- milestones;
- dependencies;
- risks;
- deliverables;
- reporting routines.

## Principle

The framework supports structured diagnosis and improvement. It is not intended to replace an accredited ISO 9001 certification audit.
