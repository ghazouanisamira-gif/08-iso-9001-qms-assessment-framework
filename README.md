# ISO 9001:2015 — QMS Assessment & Implementation Framework

**Academic Case Study | Final-Year Master's Project | 2019–2020**

## Overview

An anonymized academic case study demonstrating how a Quality Management System (QMS) can be assessed and structured using the principles of **ISO 9001:2015**, with a complementary **project-management and governance perspective**.

The work focuses on understanding an organization and its processes, identifying gaps and risks, structuring improvement priorities, and translating findings into an implementation roadmap.

> **Scope note:** This is an academic assessment and initiation project. It does not represent a completed ISO 9001 certification, an accredited certification audit, or a certification-readiness conclusion.

## Approach

**Understand → Diagnose → Map → Assess → Prioritize → Plan → Improve**

The framework combines:
- ISO 9001:2015 requirement analysis
- Process approach and process mapping
- Interested-party and risk analysis
- QMS self-assessment
- Gap and priority analysis
- Corrective/improvement planning
- Implementation roadmap
- PMO-style governance, milestones, responsibilities and follow-up
